# Varinder Pal Singh Portfolio

Personal portfolio for [Varinder Pal Singh](https://github.com/Varind3r), hosted with GitHub Pages at:

**https://varind3r.github.io/**

This is a dependency-free static site built with HTML, CSS, and JavaScript. It presents my WordPress and PHP work, skills, experience, resume, and contact information.

## Local preview

Open `index.html` directly, or run:

```sh
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Structure

- `index.html` - Portfolio content and page metadata
- `styles.css` - Responsive layout and visual design
- `script.js` - Header and mobile navigation behavior
- `assets/` - Resume and hero image
- `screenshots/` - Desktop and mobile previews
