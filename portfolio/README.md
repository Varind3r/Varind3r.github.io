# Varinder Pal Singh Portfolio

A static portfolio website generated from the resume content in this workspace.

## Files

- `index.html` - Portfolio page
- `styles.css` - Responsive visual design
- `script.js` - Header and mobile navigation behavior
- `assets/hero-workspace.png` - Generated hero image
- `assets/varinder-pal-singh-resume.pdf` - Downloadable resume

Open `index.html` directly in a browser, or serve the folder with any static web server.
